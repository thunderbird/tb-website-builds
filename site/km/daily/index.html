Know the Risks First

Thunderbird Daily is for development.

Thunderbird Daily is not intended for general use. As a precaution, assume it will be unstable and result in data loss. We recommend you join the Daily forum to keep up to date with any news.

Read Docs រាយការណ៍បញ្ហា ពិភាក្សា

ចាត់វិធានការប្រុងប្រយ័ត្ន

  • Prioritize frequent, thorough backups of your daily profile.
  • Expect very frequent, disruptive updates and install strictly to a daily-specific directory.
  • Limit mail filters to a single daily profile, or preferably, avoid them.
  • សន្មតថាកម្មវិធីបន្ថែមភាគច្រើននឹងមិនដំណើរការទេ។
  • Avoid using POP accounts with daily. If necessary, configure to leave messages on the server indefinitely.
